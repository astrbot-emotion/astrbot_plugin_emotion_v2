# 情绪系统 v2（AstrBot 插件）

给聊天机器人一套**会自己变化、且能被测量**的情绪。

四层结构，只有一层碰模型：

```
① 判定层   对方这句话是什么情绪     规则 + 语义 + 语境仲裁（多标签）
② 模糊层   她"说不上来"的感受       19 个词 × 0~10，按滑动值累加
③ 情绪层   她自己的七情             纯数学：底/冲、衰减、压制、主导
④ 语气层   她怎么说话               十一个旋钮 → 注入 system_prompt
```

---

## 安装

```
1. 整个目录放到：<AstrBot>/data/plugins/astrbot_plugin_emotion_v2/
2. 重启 AstrBot
3. 面板：设置 → 插件 → 情绪系统 v2
```

启动成功日志：

```
[emotion-v2] 已恢复 N 个会话
[emotion-v2] 心跳已启动（默认 15.0 分钟）
```

## 依赖

**零第三方依赖**，只用 AstrBot 自带的 Python 环境。

| 可选能力 | 需要什么 | 不开会怎样 |
|---|---|---|
| LLM 复核 | 任意 chat provider | 只走规则判定 |
| embedding 报警 | `embedding_model`（如 `BAAI/bge-m3`） | 少一层"可疑句"提醒 |

## 和 astrbot_plugin_emotion_core 的关系

**不依赖它，但两者会同时往 `system_prompt` 注入。**

两个都装请二选一：

- 用本插件的情绪 → 关掉 core 的注入（`inject.enabled: false`），保留它的主动说话
- 用 core 的心境 → 关掉本插件顶部的「语气注入」开关

本插件自带开关，状态存 `inject.json`，重启不丢。

> **注入默认是「开」**（首次安装就会往 `system_prompt` 追加一段情绪描述，
> 约 200~240 字）。不想让它改语气，装完先去面板把它关掉。

## 隐私与数据

**这个包不含任何用户数据。** 没有状态文件、没有聊天记录、没有词表以外的个人信息。

运行时数据都写在自己的 `plugin_data/astrbot_plugin_emotion_v2/`（`.gitignore` 已覆盖）：

```
logs/YYYY-MM-DD.jsonl    每轮一条：说了什么、判成什么、她变成什么
state.json               当前情绪（删了从陌生人重新开始）
embeddings_*.json        embedding 缓存（如启用）
mood_share_*.json        只给 emotion_core 读的频率信号
inject.json              注入开关
```

插件**不联网**（除非你启用 LLM 复核或 embedding），**不读写人格文件**，注入只作用于当次请求。

## 自定义

### 加词

改 `lexicon.yaml`，重启即可。每组词都有注释说明它影响哪个情绪。

### 调参数

- 判定强度系数：`engine.py` 的 `JUDGE_TO_FUZZY` / `FUZZY_TO_EMO`
- 衰减速度：`Her` 类的 `HL_*` 常量
- 语气杠杆：`TONE_BASE` 与 `tone_spec()`

### 加你自己的称呼

`engine.py` 顶部：

```python
CALL_NAMES = ["宝贝", "乖", "亲爱的"]   # 改成你自己的叫法
```

## 已知边界

- 规则判定的准确率不高（133 条人工金标准上主标签约 37%），多标签覆盖更好
- 反讽、打错字、绕弯说、口头禅判不准
- 情绪是**慢慢攒的**，一句话最多让她动 2~12 分

## 说句实话

这套东西是拿**一个人的聊天记录**（367 条）+ **133 条人工标注**磨出来的，
没做过大规模语料验证，样本非常有限。所以：

- 主标签准确率 **37%**、多标签覆盖 **39~43%** —— 这是实测值，不是估的，也就这个水平
- 换个说话风格、换个场景、换个人，表现都会变
- 所有参数都是按"一个慢热的人"调的；要做别的性格，得重调
  `JUDGE_TO_FUZZY`（他的情绪→她的感受）、`FUZZY_TO_EMO`（感受→情绪）、`HL_*`（衰减速度）

**如果你觉得漏洞百出——那很正常。**
它更接近一份**可运行的参考实现**，不是成熟产品：结构、分层、数值思路可以抄，
数值必须按你自己的角色重定（照抄别人的数值，会得到别人的脾气）。

好在每一层都能单独改、单独测：`python tests/scenario.py`。
