# 情绪流转说明：用户的情绪 → 模糊层 → 她的情绪

> 对应引擎 v11.5 ／ 2026-11-01
> 这份文档只讲一件事：**一句话进来，经过哪三个台阶，变成她心里的数。**

---

## 0. 三个台阶

```
他这句话
   │
   ▼
① 判定层 ── 他的情绪（多标签，滑动 0~1）
   │           忧 0.60 ／ 思 0.42 ／ 哀 0.38 ／ 惧 0.40
   ▼
② 模糊层 ── 她"说不上来"的感受（18 个词，各 0~10）
   │           心疼 3.1 ／ 不安 2.6 ／ 在意 1.1 ／ 羞 0.8
   ▼
③ 情绪层 ── 她自己的七情（底 + 冲）
               忧 +5.4 ／ 惧 +2.3 ／ 哀 +1.0 ／ 喜 +1.4
```

**为什么中间要有模糊层：**

- 判定层说的是「他」：他在担心
- 情绪层要的是「她」：她心疼、她不安
- 中间这一步不能省——**"他担心"并不会自动变成"她心疼"，中间要过一次翻译**

---

## 1. 滑动变量是什么

判定层现在给每个情绪一个 **0~1 的连续分**，不是"命中/未命中"：

```
命中阈值 0.30 只决定"要不要显示在多标签里"
实际驱动模糊层的，是这个连续分本身
```

所以：

| 判定分 | 对模糊层的推力 |
|---|---|
| 0.38（弱） | 只有 38% 的系数 |
| 0.60（中） | 60% |
| 0.90（强） | 90% |

**同一句话说两遍，如果第二遍语气更重，分更高，模糊层涨得也更多。** 这就是"滑动"。

---

## 2. 表①：他的情绪 → 模糊层怎么变

**规则**：`模糊词增量 = 系数 × 判定分`（模糊层每个词 0~10 封顶）

| 他的情绪 | 她的模糊词 | 系数 | 为什么 |
|---|---|---|---|
| **喜** | 在意 | 3.0 | 被夸 → 她更在意他 |
| | 羞 | 2.5 | 被夸会羞 |
| | 释然 | 1.0 | 关系是好的，松一口气 |
| **乐** | 好奇 | 2.0 | 他逗她 → 她想接下去 |
| | 释然 | 1.5 | 玩得开心 |
| **哀** | 心疼 | 3.0 | 他难受 → 她心疼（最主要的） |
| | 不安 | 1.0 | 也跟着不安 |
| **惧** | 心疼 | 2.0 | 他怕 → 她心疼 |
| | 不安 | 2.5 | 她被传染 |
| **怒** | 委屈 | 3.0 | 他凶 → 她委屈 |
| | 不安 | 2.0 | 关系不稳 |
| **思** | 在意 | 2.5 | 他想她 → 她更在意 |
| | 羞 | 2.0 | 被想念会羞 |
| | 期待 | 1.0 | 期待见面 |
| **忧** | 心疼 | 2.0 | 他担心 → 她心疼 |
| | 不安 | 2.0 | 一起不安 |
| **威胁** | 委屈 | 6.0 | 被威胁是重的 |
| | 不安 | 6.0 | 心里不踏实 |
| | **害怕** | 5.0 | **被吓到**（与不安不同：不安是轻微发慌，害怕是想躲） |
| **厌弃** | 委屈 | 5.0 | |
| | 失落 | 4.0 | |
| | 疏离 | 5.0 | |
| **安抚** | 释然 | 4.0 | 被哄好 |
| | 羞 | 1.0 | |

**多标签就是逐条叠加**：一句「我担心你以后会离开我」有四个标签，就同时走四行。

### 一个容易漏的点

**威胁 / 厌弃 / 安抚 这三个标签不在 `multi` 里**——它们是 `multi` 算完之后才覆盖上去的。
所以接链时必须把「最终 label」也算一路，否则这三表永远不生效。代码里 `fuzzy_from_judge()` 就是这么做的：

```python
pairs = [(label, strength)]                    # 最终 label 先算
for d in multi:                                # 再多标签
    if d["name"] != label: pairs.append(...)
```

## 3. 表②：模糊层 → 她的情绪怎么变

**规则**：`情绪增量 = 系数 × 该模糊词的当前值`

| 模糊词 | 影响她的 | 系数（每 1 点模糊值） |
|---|---|---|
| **委屈** | 哀 | +0.8 |
| | 忧 | +0.4 |
| **不安** | 惧 | +0.5 |
| | 忧 | +0.5 |
| **害怕** | 惧 | **+1.2** |
| | 哀 | +0.2 |
| **心疼** | 忧 | +0.6 |
| | 哀 | +0.2 |
| **失落** | 哀 | +0.6 |
| | 思 | +0.3 |
| **羞** | 喜 | +0.4 |
| | 乐 | +0.3 |
| **期待** | 喜 | +0.3 |
| | 乐 | +0.2 |
| **好奇** | 喜 | +0.2 |
| **在意** | 思 | +0.4 |
| **试探** | 惧 | +0.15 |
| **自责** | 哀 | +0.5 |
| **疏离** | 惧 | +0.6 |
| | 哀 | +0.4 |
| **释然** | 忧 | **−0.5** |
| | 不安 | **−0.5** |
| **倦** | 乐 | **−0.3** |
| **关心** | 喜 | +0.3 |
| **求证** | 惧 | +0.1 |
| **教育** | 怒 | +0.2 |
| **别扭** | 怒 | +0.2 |
| **不确定** | — | 只影响语气，不进情绪 |

**注意有三条是负号**：释然会压忧和不安，倦会压乐。模糊层不只是加，也会减。

## 4. 一个完整例子

**他说：「我担心你以后会离开我」**

### 第一步：判定层（多标签，滑动）

| 情绪 | 分 | 依据 |
|---|---|---|
| 忧 | 0.60 | 分离担忧 |
| 思 | 0.42 | 提前的思念 |
| 惧 | 0.40 | 怕失去 |
| 哀 | 0.38 | 想到分离 |

### 第二步：模糊层（按表①，逐条叠加）

| 来自 | 模糊词 | 增量 |
|---|---|---|
| 忧×0.60 | 心疼 +2.0×0.60 = **+1.20** | |
| | 不安 +2.0×0.60 = **+1.20** | |
| 思×0.42 | 在意 +2.5×0.42 = **+1.05** | |
| | 羞 +2.0×0.42 = **+0.84** | |
| | 期待 +1.0×0.42 = **+0.42** | |
| 惧×0.40 | 心疼 +2.0×0.40 = **+0.80** | |
| | 不安 +2.5×0.40 = **+1.00** | |
| 哀×0.38 | 心疼 +3.0×0.38 = **+1.14** | |
| | 不安 +1.0×0.38 = **+0.38** | |

**合并后模糊层增量：**

```
心疼 3.14   不安 2.58   在意 1.05   羞 0.84   期待 0.42
```

### 第三步：情绪层（按表②）

| 模糊词 | 值 | 情绪 |
|---|---|---|
| 心疼 | 3.14 | 忧 +1.88、哀 +0.63 |
| 不安 | 2.58 | 惧 +1.29、忧 +1.29 |
| 在意 | 1.05 | 思 +0.42 |
| 羞 | 0.84 | 喜 +0.34、乐 +0.25 |
| 期待 | 0.42 | 喜 +0.13、乐 +0.08 |

**合计**：忧 **+5.37**、惧 **+2.29**、哀 **+1.03**、喜 **+1.36**、乐 **+0.74**、思 +0.42

### 第四步：她的实际数值

| | 现状（不经模糊层） | 经模糊层后 |
|---|---|---|
| 喜 | 32 | 33 |
| 哀 | 2 | 3 |
| 惧 | 0 | 2 |
| 忧 | 13 | **18** |
| 思 | 0 | 0（0.42 未过显示线） |

**结论：她被这句话推得更"忧"了，而且多了 2 分惧（轻微不安）。方向对。**

## 5. 模拟结果（367 条真实对话）

| 指标 | 值 |
|---|---|
| 有变化的句子 | **224 / 367（61%）** |
| 单句最大变化 | **12.4 分** |
| 平均变化 | **1.96 分** |

对比之前"直接遍历多标签"的方案（只有 6.8% 变化、平均 0.4 分），
**经过模糊层以后，影响面更大也更平滑**——因为它把"他的一句话"翻译成了"她的一堆细碎感受"，再由这些感受慢慢汇成情绪。

## 6. 三个需要你定的参数

| # | 参数 | 现在的值 | 影响 |
|---|---|---|---|
| ① | 表① 的系数 | 2.0~6.0 | 决定"他能多快拨动她的感受" |
| ② | 表② 的系数 | 0.15~0.8 | 决定"感受能多快变成情绪" |
| ③ | 情绪层单轮上限 | 每项 ±20 | 防止一句话打满 |

**现在的组合是"轻而慢"的**：一句话最多让她动 2~12 分，符合"情绪是慢慢攒的"。

如果要更敏感，调 ①②；如果要更迟钝，也调 ①②。
**先把这套跑起来看效果，再调，比较稳。**
