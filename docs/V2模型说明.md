# 情绪系统 v2 · 模型说明

> 引擎 v11.4 ／ 插件 3.0.0 ／ 更新于 2026-11-01
> 这份文档描述**引擎实际怎么算**，不是设计愿望。所有数值都能在 `engine.py` 里对上。

---

## 0. 一句话

**他说的每句话，先被判定层拆成「他此刻是什么情绪」（可多标签），再由情绪层按她自己的规则算出「她自己是什么情绪」（七情，带底与冲、会衰减、会互相影响），最后翻译成十一个语气杠杆，注入当次 `system_prompt`——只改这一次说话的样子，不动人格。**

---

## 1. 核心：两侧必须分开

```
他：「我担心你以后会离开我」
      │
      ├─ 判定层（判的是「他」）
      │     忧 0.60 ／ 思 0.42 ／ 哀 0.38 ／ 惧 0.50     ← 多标签同时亮
      │
      └─ 情绪层（算的是「她」）
            喜 32 ／ 忧 13                                  ← 她自己的数值
```

### 为什么不能合成一张映射表

如果写成「用户忧 → 她忧」，就会丢掉这条句子里真正重要的东西：

> **他说怕失去她——这件事让她高兴。**

「担心你考不上」和「担心你离开我」，用户的情绪都是**忧**，
但对她意味着的事完全不同：前一种是**她心疼他**，后一种是**她被在乎**。

所以：

| 层 | 回答的问题 | 输入 | 输出 |
|---|---|---|---|
| 判定层 | **他现在什么情绪** | 他这一句 + 前几句 | 主标签 + 多标签 |
| 情绪层 | **她自己什么情绪** | 判定结果、语义事件、时间、她自己的历史 | 七情（底/冲） |

**判定层永远不说"她该怎样"，情绪层也永远不抄判定层的结论。**

## 2. 判定层

### 2.1 流水线

```
原句
 ├─① 词义：词表命中（关键词、句式正则）
 ├─② 语义：句子结构（时态指向、句式、程度）——不看单个词
 ├─③ 语境：前 8 句 + 否定/假设/安抚/追问 → 对每个情绪给 +1/0/−1
 ├─④ 仲裁：词义 vs 语义，用语境裁决
 ├─⑤ 保护：威胁 / 厌弃 / 安抚 / 短句兜底
 └─⑥ 输出：主标签、强度、多标签、仲裁日志
```

### 2.2 词义（词表命中）

| 情绪 | 主要来源 | 典型词/句型 | 分 |
|---|---|---|---|
| 喜 | `PRAISE`、`POSITIVE_HINT`、`CARE_Q`（关心她） | 你真厉害 / 喜欢你 / 心疼你 | 0.35–0.67 |
| 怒 | `ANGRY_WORDS`、`REPROACH_PAT`、`COMMAND_PAT` | 你还不 / 怎么又 / 罚你去 | 0.55–0.65 |
| 哀 | `score_sorrow`（收着说、自我否定、示弱、深夜） | 算了 / 我好累 / …… | 0.30–0.60 |
| 乐 | `score_bright`、`JOKE`、`PLAY_PAT` | 哈哈 / 逗你 / 会小狗叫吗 | 0.45–0.55 |
| 惧 | `score_fear`（求证、假设坏结局、说怕、触及结束） | 你还记得…吗 / 是不是不… | 0.35–0.60 |
| 忧 | `score_worry`（担心/万一/会不会/怕，或未来词 ≥2） | 我担心 / 万一 / 以后 | 0.35–0.45 |
| 思 | `score_miss`（想你/想见，或提过去） | 我想你了 / 那时候 | 0.35–0.55 |

### 2.3 语义（结构规则）

看的是**句子怎么造**，不是出现了哪个词：

| 规则 | 触发条件 | 输出 |
|---|---|---|
| 近期事件 | 明天/下周/最近 **×** 考/面试/答辩/实习/期末 | 忧 0.54 |
| 未来+关切+你 | 未来词 **×** （关切 or 不确定）**×** 有"你" | 忧 0.64 |
| 未来话题多 | 未来词 ≥2 **×** （疑问 or 关切） | 忧 0.46 |
| 过去+疑问+你 | 过去词 **×** 疑问 **×** 有"你" | 思 0.62 |
| 多次提过去 | 过去词 ≥2 **×** 疑问 | 思 0.45 |
| **分离担忧** | 分离词（离开/走/失去/没有你/别走）**×** 担心或未来 **×** 人称 | **忧 0.60／思 0.42／哀 0.38／惧 0.50** |
| 威胁结构 | 绝对词（永远/再也不/彻底）**×** 消失类动词 **×** 人称 | 惧 0.70 |
| 质问/指责 | "还…吗/呢"结尾，或指责词 + 你 | 怒 0.60 |
| 笑/感叹 | 哈哈/嘿嘿/233，或连续感叹号 | 乐 0.52 |
| 亲昵 | 宝贝/亲爱的/喜欢你/爱你/乖 | 喜 0.56 |

**分离担忧是四标签同时亮的唯一入口**，命中即返回，不再走后面的规则。

### 2.4 语境（检查器）

每个检查器只回答 **+1 认可 / −1 否决 / 0 中立**：

| 检查器 | 触发 | 效果 |
|---|---|---|
| 否定辖域 | 不怕 / 不担心 / 没生气 | 否决对应情绪 |
| 假设语境 | 如果/要是/万一 + 未来 | 否决惧，认可忧 |
| 安抚 / 玩笑 | 逗你的 / 别怕 / 有我在 | 否决惧与怒 |
| 连续追问 | 连续 ≥2 个问句 | 否决喜与乐（那是试探） |
| 近轮敌意 | 前 3 句里 ≥2 句带敌意 | 否决喜 |

### 2.5 仲裁

```
词义 = L（分 lv）   语义 = S（分 sv）
① L == S            → 直接用（取较高分）
② 语义为空           → 用词义
③ L ≠ S：
     语境认可 S     → 用 S
     语境否决 S     → 用 L
     语境中立       → 谁分高用谁（最匹配）
```

每次仲裁都留日志：

```python
judge["arb"] = {
    "词义": ["喜", 0.67], "语义": ["忧", 0.60],
    "采用": "忧", "理由": "最匹配", "语境": "中立"
}
```

真实例子：

```
我担心你以后会离开我
  词义=喜(0.67)  语义=忧(0.60)  采用=忧(最匹配)
```

### 2.6 保护规则（优先级高于普通判定）

| 规则 | 作用 | 例子 |
|---|---|---|
| 威胁 `threat_level` | 直接判「威胁」，跳过普通判定 | 我要永远删除你 → 惧底 +8 |
| 厌弃 `reject_hit` | 判「厌弃」（推开词 + 语境 + 剩余长度） | 我真讨厌你 |
| 安抚 | 有安抚词且强度 <0.5 → 「安抚」 | 逗你的，别怕 |
| 否定辖域 | 只做提示，不改分 | 我不怕 |
| 假设句 | 惧 ×0.4，忧 抬到 0.40，怒 封顶 0.3 | 如果给你设定固定值 |
| 短句兜底 | ≤4 字且无明确命中 → 全部清零（判平静） | 嗯 / 哦 |
| 容错门槛 | 模糊匹配要求 ≥4 字（3 字只认完全相等） | 「不要我」不会误伤「不要打字」 |
| 求证抑制 | 思 ≥0.35 且惧 ≤0.55 → 惧压到 思−0.02 | 你还记得第一天吗 → 思 |

### 2.7 输出

```python
judge = {
  "label": "忧",              # 主标签（最高分）
  "strength": 0.60,
  "multi": [                  # 所有 ≥0.30 的情绪
    {"name": "忧", "score": 0.6},
    {"name": "思", "score": 0.42},
    {"name": "哀", "score": 0.38},
    {"name": "惧", "score": 0.5},
  ],
  "arb": {...},               # 仲裁日志
  "why": "分离担忧",          # 依据
}
```

**语义层的标签也会并入 `multi`**，所以「分离担忧」能一次点亮四个。

## 3. 模糊层（"说不上来的那点感觉"）

> 完整流转（判定 → 模糊 → 情绪）见 [`情绪流转说明.md`](情绪流转说明.md)

19 个词，各自 0–10 分，按权重渗进情绪与语气：

```
委屈 不安 在意 试探 不确定 期待 失落 心疼 别扭 自责
羞 好奇 疏离 释然 倦 关心 求证 教育 害怕
```

**「害怕」是第 19 个词**（2026-11-01 用户批准）：不安是轻微发慌，害怕是被吓到想躲，两回事。

### 双向转换（`CONVERT`）

**他的模糊感受 → 她的反应**：

| 他 | 她 |
|---|---|
| 委屈 | 心疼 +2、忧 +1.0 |
| 不安 | 心疼 +2 |
| 期待 | 期待 +1、喜 +1.0 |
| 试探 | 紧张 +1 |
| 关心 | 羞 +1、喜 +0.8 |
| 教育 | 别扭 +1 |
| 失落 | 心疼 +1、忧 +0.6 |
| 自责 | 心疼 +2 |
| 倦 | 心疼 +1、忧 +0.6 |
| 羞 | 乐 +1.0 |
| 好奇 | 喜 +0.5 |
| 疏离 | 惧 +1.0、哀 +0.8 |

## 4. 情绪层（她自己）

### 4.1 七情与「底 / 冲」

| | 说明 |
|---|---|
| **冲** | 当下那一下，分钟级。被夸、被凶，先动的是它 |
| **底** | 事过去以后剩下的，天级 |
| **读数** | 底 + 冲（怒还要再乘惧的压制系数） |

七情：**喜 怒 哀 乐 惧 思 忧**

### 4.2 衰减

```python
dt  = clamp(间隔秒数, 1, 7 天)
fac = 0.5 ** (dt / 半衰期)
```

| 情绪 | 冲·半衰 | 底·半衰 | 备注 |
|---|---|---|---|
| 喜 | 30 分钟 | 30 天 | 底地板 **20**（陌生人是 20，不是 0） |
| 怒 | 30 分钟 | 3 天 | 伤害账单独，30 分钟 |
| 哀 | 2 小时 | 1 天 | 底封顶 90 |
| 惧 | 1 小时 | 3 天 | 底地板 **2**（真怕过就留痕） |
| 乐 | 30 分钟 | 底向「底色」回归 2 小时 | 底色 30–75，默认 55 |
| 思 | 6 小时 | 5 天 | — |
| 忧 | 2 小时 | 12 小时 | — |

### 4.3 封顶

```
喜 95 ／ 怒 95 ／ 哀 95 ／ 惧 95 ／ 忧 95 ／ 乐 100 ／ 思 100
```

### 4.4 互相影响

| 耦合 | 实现 | 数值 |
|---|---|---|
| **惧压怒** | 惧 ≤60 不压；越高压得越狠 | `max(0.30, 1 − 0.70×(惧−60)/35)`，惧 95 时怒只剩 30% |
| **喜放大** | 她越高兴，被触发的东西越大 | `xi_amp = 1 + 0.60 × clamp((喜−35)/65)`，1.00～1.60 |
| **思靠时间** | 不是谁惹的，是"多久没联系" | `思底 += 78 × si_scale × 天数`，`si_scale=(喜−35)/65`；**喜 ≤35 完全不起思** |
| **负面压乐** | 哀/惧越高，乐的底色越低 | `neg = max(哀,惧)/100`，`obs 底色 −= 0.8×neg×min(小时,3)` |

### 4.5 事件表 A：他的情绪类别 → 她的反应

| 他 | 她的动作 |
|---|---|
| 喜 | 乐 +v×8×amp；喜冲 +v×25×(1−喜/95)×amp；喜底 +0.1（v>0.4 时 +0.5） |
| 乐 | 同喜，强度 ×0.6 |
| 哀 | 哀冲 +v×7×amp；哀底 +0.5；乐 −v×3；喜冲 ×0.92 |
| 惧 | 哀冲 +v×3（心疼） |
| 怒 | 惧冲 +0.55×v×80；哀冲 +0.30×v×10；委屈/不安 |
| 威胁 | 惧冲 +sev×63×amp；惧底 +sev×8×amp；怒冲 +sev×10×amp；喜冲 ×0.92 |
| 厌弃 | 惧冲 +0.70×45×0.75；哀冲 +0.70×20×1.2；怒/乐降；惧底 +2 |
| 安抚 | 惧/怒/哀 一起降（`soothe`） |
| 被逗 | 乐冲 +9×amp（冲上限 25）；喜冲 +2×amp |
| 说想你 | 喜冲 +12×amp；乐 +2；思冲 +10 |

### 4.6 事件表 B：她的价值判断（**与他的情绪类别无关**）

这三条由情绪层**自己识别关键词**，不看判定层的 label：

| 事件 | 触发 | 她的反应 | 为什么 |
|---|---|---|---|
| **被在乎** | 分离词 **×** 舍不得/怕失去/担心你走 | 喜冲 +10×amp；喜底 +1.5 | 有人舍不得她 |
| **分离话题** | 离开 / 走 / 失去 / 没有你 / 别走 | 忧冲 +4×amp；忧底 +3；哀冲 +2×amp | 关系不稳，她会不安 |
| **被需要** | 没有你怎么办 / 靠你了 / 只有你 | 喜冲 +6×amp | 她被需要 |

### 4.7 主标签落到她身上的两条特例

| 他的主标签 | 她的反应 |
|---|---|
| 思 | 喜冲 +8×amp、乐 +3、思冲 +8（**被想念让她高兴**） |
| 忧 | 忧冲 +6×amp（跟着担心） |

## 5. 主导情绪 + 滞回

```
优先级：惧 1.00 ＝ 忧 1.00 > 思 0.95 > 怒 0.90 > 哀 0.85 > 乐 0.60 ＝ 喜 0.60
主导 = argmax(读数 × 优先级)，且读数要过门槛
```

门槛：惧 ≥22、忧 ≥15、思 ≥15、怒 ≥28、哀 ≥22、乐/喜 要高于底色或喜底 ≥40。

**滞回**（防止每句翻脸）：

| 规则 | 数值 |
|---|---|
| 挑战者要超出当前主导 | ≥5 分 |
| 当前主导最短保持 | 15 分钟 |
| 例外：某个「冲」一次涨 ≥25 且结果 ≥30 | 立刻换 |

## 6. 语气层（11 个杠杆）

底座 → 情绪与模糊层调整 → 每个杠杆 0–1：

| 杠杆 | 底座 | 主要拉动 |
|---|---|---|
| 软硬 | 0.50 | +0.85×负面（哀/惧）；−0.95×怒 |
| 玩笑 | 0.20 | +0.38×愉悦 +0.12×亲近；−0.85×负面 |
| 语气词 | 0.25 | +0.62×愉悦 +0.10×亲近；−0.70×倦 |
| 称呼 | 0.30 | +0.62×愉悦 +0.12×亲近；−0.60×疏离 |
| 主动性 | 0.20 | +0.35（他问了）+0.45×(好奇/在意)；−0.45×别扭 |
| 句长 | 0.35 | +0.55×愉悦；−0.60×负面 −0.35×怒 −0.45×倦 |
| 连发 | 0.25 | +0.42×愉悦；−0.45×负面 |
| 反问 | 0.20 | +0.55×(在意/好奇)+0.35×试探；−0.50×别扭 −0.45×怒 |
| 省略号 | 0.15 | +0.70×委屈 +0.55×别扭 +0.45×负面；−0.60×愉悦 |
| 沉默 | 0.05 | +0.55×别扭 +0.28×倦 +0.30×负面；厌弃 +0.20×强度 |
| 哀求 | 0.00 | +0.62×威胁强度×(0.5+0.5×惧) +0.35×惧底 +0.22×委屈 |

其中：

```python
愉悦 = (喜 − 20)/45 + (乐 − 55)/45        # 喜的中性基准是 20，不是 50
亲近 = (like − 20)/45                      # 长期亲近度，让"平静"也分两种
负面 = max(哀, 惧)/100
```

## 8. 记忆桥（LivingMemory → 情绪）

读 LM 已经注入到 `request.extra_user_content_parts` 里的 `<RAG-Faiss-Memory>` 块，解析后折成她的「底」：

| 记忆内容 | 她 |
|---|---|
| 正面（开心/考上/厉害） | 喜 +0.03×w、乐 +0.30×w |
| 负面（累/难过/失败） | 哀 +0.50×w、思 +0.40×w |
| 关切（考试/加班/生病）且没被好事盖住 | 忧 +3.00×w |
| 约定（答应/说好/永远） | 喜 +0.03×w、喜欢 +0.02×w、思 +0.10×w |
| 冲突（讨厌你/吵架/失望） | 哀 +0.80×w、思 +0.10×w |

- `w = 0.6 + 0.4 × 重要度`
- 同一条记忆 12 小时内只算一次
- **量很小**：一条"他明天考试"让她忧 +1~1.5，而他自己说一句"累"是 +14
- 单向只读，不 import LM 的代码（它 AGPL-3.0，这样不传染）

## 9. 多会话与持久化

| 项 | 实现 |
|---|---|
| 会话隔离 | `sessions[umo]`，每个对话一份七情、模糊层、最近文本 |

| 停机追赶 | 15 分钟一步补算，**最多 672 步（7 天）** |

## 11. 已知边界（必须知道）

## 附：一次完整的计算（真实例子）

**他说：「我担心你以后会离开我」**

```
① 词义：喜 0.67（"担心你"被当关心）
② 语义：分离担忧 → 忧 0.60 / 惧 0.50 / 思 0.42 / 哀 0.38
③ 语境：中立
④ 仲裁：词义喜(0.67) ≠ 语义忧(0.60) → 最匹配 → 忧 0.60 更高？
        实际：0.67 > 0.60，但语义标签全部并入多标签
⑤ 输出：主=忧，多=[忧0.60, 惧0.50, 思0.42, 哀0.38]

她侧：
   • 事件A：主标签忧 → 忧冲 +6
   • 事件B：被在乎 → 喜冲 +10、喜底 +1.5
   • 事件B：分离话题 → 忧冲 +4、忧底 +3、哀冲 +2
   → 喜 32 ／ 忧 13 ／ 哀 2
```

**结果：他 忧思哀惧，她 喜 + 忧。**
